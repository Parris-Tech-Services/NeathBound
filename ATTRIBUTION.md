# Open asset sources

NeathBound uses original code, writing, composition and UI. A small number of
freely licensed or public-domain media files are used as raw visual material.

## Cavern panorama

**Ishigaki Stalactite Cave 01.jpg**  
Author: AsPJT  
Source: Wikimedia Commons  
License: CC0 1.0 Universal / public-domain dedication  
Source page: https://commons.wikimedia.org/wiki/File:Ishigaki_Stalactite_Cave_01.jpg

Used as atmospheric cavern imagery in the main location panorama, promo art and
some story-card crops. NeathBound applies colour overlays, masks, silhouettes,
cropping and filters.
